# Mehak Manhas — Portfolio

A cinematic, scroll-driven personal portfolio built with React, TypeScript, Framer Motion, and Tailwind CSS.

## ✨ Features

- **Animated Hero** — full-screen background video with smooth fade loop, scroll parallax, and entrance animations
- **Hire Me Modal** — cinematic popup with full-bleed video background, spring physics, WhatsApp & email CTAs
- **Storytelling Scroll Animations** — project cards fly in from different directions using `useScroll` + `useSpring` per card
- **Experience Timeline** — staggered bullet reveals with glass-morphism cards
- **Skills Section** — animated progress bars triggered on scroll
- **Contact Section** — parallax video background, WhatsApp conversation starter
- **Fluid Background** — fixed full-page video + animated aurora gradient blobs + grain texture
- **Custom Cursor** — smooth trailing cursor
- **Lenis Smooth Scroll** — buttery smooth page scrolling
- **Scroll Progress Bar** — thin top indicator

## 🛠️ Tech Stack

| Layer | Tools |
|---|---|

| Animation | Framer Motion |
| Styling | Tailwind CSS |
| Smooth Scroll | Lenis |

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
